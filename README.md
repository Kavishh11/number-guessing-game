# Number Guessing Game 🎯

A simple and interactive **Number Guessing Game** built using Python. The player chooses a difficulty level and tries to guess a randomly generated number within a limited number of attempts.

## 🎮 Features

* **Easy Mode** — Guess a number between 1 and 50 with 10 attempts
* **Medium Mode** — Guess a number between 1 and 100 with 7 attempts
* **Hard Mode** — Guess a number between 1 and 200 with 5 attempts
* Random number generation
* High/low hints
* Attempt counter
* Remaining-attempt display
* Win and game-over messages

## 🛠️ Technologies Used

* Python
* Random module

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
python Number_guessing.py
```
